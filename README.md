# 图片对比工具

一个基于 Vue 3 + Vite 的本地图片对比工具。支持在浏览器中直接加载两张图片，并在不同模式下查看差异：分屏、淡化、滑块、高亮、相减和文件详情。

## 特性

- 纯本地处理，图片文件不会上传到服务器。
- 支持拖拽或点击选择两张图片。
- 提供多种对比模式：分屏、淡化、滑块、高亮、相减、文件详情。
- 支持缩放、拖拽平移和适应窗口。
- 支持浅色、深色和跟随系统主题。
- 可通过本地 Python 脚本启动服务并自动预载指定图片。

## 支持格式

当前支持以下图片格式：PNG、JPEG、WebP、GIF、BMP。

## 环境要求

- Node.js 18 或更高版本
- npm
- Python 3.9 或更高版本（仅在使用 scripts/compare.py 时需要）

## 安装

```bash
npm install
```

## 开发

启动本地开发服务器：

```bash
npm run dev
```

然后在浏览器中打开终端提示的地址。

## 构建

生成生产版本：

```bash
npm run build
```

构建结果会输出到 dist 目录。

## 使用 Python 脚本启动对比服务

项目提供了 scripts/compare.py，可以直接用两张本地图片启动一个对比服务，并在浏览器中自动打开：

```bash
python scripts/compare.py 左图路径 右图路径
```

示例：

```bash
python scripts/compare.py a.png b.png --mode highlight
```

常用参数：

- `--mode`：指定初始对比模式，支持 split、fade、slider、highlight、subtract、details。
- `--host`：监听地址，默认是 127.0.0.1。
- `--port`：监听端口，默认是 8000。
- `--no-browser`：启动服务后不自动打开浏览器。

脚本会在需要时自动执行前端构建，然后启动一个本地 HTTP 服务。服务页会通过 `?autoload=1` 自动加载指定的两张图片。

## 功能说明

- 分屏：左右并排显示原始图片和修改图片。
- 淡化：在同一视图中叠加两张图片，并用透明度控制对比。
- 滑块：拖动分割线查看两张图片的覆盖差异。
- 高亮：计算像素级差异并高亮显示变化区域。
- 相减：显示两张图片的像素差结果。
- 文件详情：显示图片尺寸、格式、大小、修改时间等信息。

## 注意事项

- 浏览器需要支持 createImageBitmap 和 Canvas 2D。
- 处理超大图片时，工具会限制画布尺寸和像素总量，以避免浏览器性能问题。
- 图片仅在当前浏览器会话内处理，不会被上传到远程服务。
